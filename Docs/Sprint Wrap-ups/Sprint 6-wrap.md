By the end of Sprint 6, recipes should be able to belong to one or more categories.

The Recipe Book should automatically display recipes alphabetically and allow the user to filter the book by category while keeping the results in alphabetical order.

- [x] The Recipe Book automatically displays recipes A–Z
- [x] The Recipe Book can be filtered by category
- [x] Filtered recipes remain A–Z
- [x] Search works alongside category filtering
- [x] Recipes without categories still work normally
- [x] Existing Recipe App features still work correctly
